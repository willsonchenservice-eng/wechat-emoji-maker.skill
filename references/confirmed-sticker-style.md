# Confirmed Integrated Die-Cut Sticker Style

本项目当前确认的主生产风格。只要用户没有另行指定，批量表情默认采用本规范。

## 视觉合同

- 一张图就是一张完整贴纸：角色、动作、道具、主文案和装饰共同组成一个连续的不规则轮廓。
- 使用浅灰色外部背景和厚白色不规则切边，形成清晰的贴纸感与轻微投影。
- 中文主文案使用夸张、圆润、略带手绘笔触的黑体展示字；黑色为主，按情绪用红色强调。
- 文案必须由图像模型在同一次生成中直接画入画面，成为构图的一部分；不得先生成空图，再用本机后期叠字。
- 角色和道具要形成高密度但可读的情绪场景：股票图表、手机、研报、红绿箭头、感叹号、汗滴、眼泪等只服务于关键词。
- 单人、双人按语义分配；不能因为使用同一套参考图就强行让两个 IP 同时出现。

## 必须写入提示词

1. `Text (verbatim)` 放入准确原文，并指定明确换行。
2. 明确“文字融入贴纸构图，不是单独文字框”。
3. 明确厚白色不规则切边、浅灰外部背景、手绘展示字、黑红强调色。
4. 明确“不得复制风格参考图中的其他文案、logo 或水印”。
5. 明确角色身份参考与风格参考的角色，不混淆用途。

## 明确禁止

- 预留文字框、空白标题区、白色卡片、社交媒体封面式版面；
- 先做无文案母图再后期加字；
- 让参考图中的其他标题、气泡、品牌或随机小字污染目标文案；
- 用一个固定模板批量复制所有关键词的动作和构图。

## 交付与验收

- 批量前先生成 1 张风格对齐测试；用户确认后再批量生成。
- 每张独立调用、独立保存、独立检查主文案和 IP 身份。
- 重点检查：主文案逐字准确、白色切边连续、主体未被文案遮挡、缩略图仍能读出动作和关键词。
- 需要封面、横幅、图标或打赏图时，复用角色和线稿/配色关系；不要把表情贴纸直接拉伸成其他物料。
